# Product overview

Loots (formerly Ken OS) is a private, hosted workspace for one developer — each
workflow is a module inside one Next.js app, and only the configured owner
can sign in. See the [README](../../README.md) for the current module list
and the [product brief](brief.md) for the original MVP scope and decisions.

Each module has its own product doc: [Profile and resume builder](profile-resume.md),
[Engineering, Claude first](../architecture/engineering-claude-first.md),
[Project Memory](project-memory.md), [Job Finder](job-finder.md),
[Blog Writing Studio](blog-writing-studio.md), [CV tailoring](cv-tailoring.md).
[App language](app-language.md) sets the copy voice used across all of them.
