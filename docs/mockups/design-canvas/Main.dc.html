Changes from this brief

  1. A frame opens at 100%, scrolled to its top left, so placed components read at their real size. D1 shows Fit (38%), the whole frame with its edge and header tab.
  2. C1: every palette row shares one component icon. Loots has no per-component icon set, and inventing fifteen would be a new asset family.
  3. D2: the dragged Input shows a live X / Y readout under it and a dashed box where it started. The brief only asks for drag; the readout makes the move legible.
  4. D6 and D7 use the Phone / Posting frame (390 × 844) so both of its side edges fit the view (D6 at 70%, D7 at 100%).
  5. F2: Frames and Palette open together from a "Frames and components" button at the left of the canvas toolbar. Drawn closed, with the inspector Sheet open on a selection.
  6. Both composed frames hold four placements (Input, Button "Save", Button "Dismiss", Badge), so E3's "Removes its 4 components too" is true of the frame being deleted.
  7. Add frame appears twice, in the page header (as the brief says) and at the foot of the Frames panel. Both open B2.

Proposals

  • Frame edge handles (D6): ink bars on the frame's own edges and corner, so they never read as a placement's blue corner squares. No new token.
  • Placement name tag (D4) and drag readout (D2): small ink tags with inverse text, reusing primary and primary-foreground. No new token.
  • Canvas dot grid: dots in the border colour on the sidebar ground, the frame on the page ground with a seam. No new token.
  • App sidebar folds to icons on /design: the same proposal Design Studio made for /studio.

Decided (2 Nov 2026, owner took every recommendation)

  1. Claude-authored frames: a small outline "Claude" badge on the Frames panel row only, never on the canvas, so the composed frame stays exactly what ships. Drawn on Desktop / Posting in every frames list.
  2. Palette grouping: flat A to Z with search until the catalogue passes about 30 components, then grouped under shadcn's own categories.
  3. Zoom on open: Fit the first time a frame opens (D1), then the last zoom per frame is remembered. The other frames show a remembered 100%.
  4. Custom size limits in Add frame: 320 to 3840 wide and 320 to 4320 tall, shown on the Custom option in B2; the field names the limit when exceeded.
  5. Undo: Ctrl Z backs out the last move or resize, since moves save on release with no save step.

No open questions left. The owner folds these into docs/mockups/design.md under Decided.
