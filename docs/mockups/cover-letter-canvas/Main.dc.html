Changes from this brief

  1. Owner, 17 Nov: a tab, not a page. The letter lives in a third Job detail tab, Cover letter, beside Description and Company. There is no /jobs/[id]/cover-letter route. The title row button (Write cover letter, then View cover letter) opens that tab instead of navigating; Save to board, the CV button and Apply stay where they are.
  2. Owner, 17 Nov: empty and error states span the tab. D1 and D7 fill the panel's full width with their content centred: Mail in muted grey for the empty state, CircleAlert in the destructive colour for the error, each beside its line. D7's retry is the same Write cover letter button as D1.
  3. Owner, 17 Nov: the phone title row wraps (C3, added). The shipped action group holds three buttons, about 400px, more than a phone's 358px, so it gets flex-wrap: CV and cover letter on one line, Apply under them.
  4. D5 follows the app's confirmation pattern: "Rewrite this letter?" / "Your edits are replaced by a new letter" / Cancel, Rewrite letter. The brief's title is a statement and "Yes, rewrite" has no object.
  5. Owner, 17 Nov: the status line reads "Edited" under an edited letter, "Written Nov 17" otherwise, so the edited state is a word and not only an enabled Save.
  6. Owner, 17 Nov: Copy letter (my recommendation, accepted): an outline button before Regenerate and Save. It copies the Textarea as it is, edits included, and shows a "Letter copied" toast. Disabled only while regenerating.
  7. The posting is a sample (Tidepool, Senior Full-stack Engineer): this canvas cannot read the live Job board. Swap a real one in at review.

Proposals

None. Tabs, Button, Textarea, AlertDialog, the sonner toaster and LoaderCircle with animate-spin are already in components/ui or the app.

Decided (17 Nov 2026, owner took both recommendations)

  1. Default tab: the page always opens on Description, so the posting reads first, even once a letter exists. View cover letter switches to the Cover letter tab.
  2. Unsaved edits when switching tabs: the edited text stays in the tab's state while the page is open, so switching to Description and back loses nothing. It still shows "Edited" until saved.
