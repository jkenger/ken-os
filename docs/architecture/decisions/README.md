# Architecture decisions

One file per decision, named `ADR-NNN-kebab-title.md` (format: `claude/.claude/agents/adr.md` in the dotfiles repo). Everything else about a feature (design, current shape) stays in its flat `docs/architecture/<feature>.md` file; this folder is only for the decision record itself — what was chosen, what the alternatives were, and why. File one only for a real architectural trade-off with alternatives considered, not a routine scoping call.
